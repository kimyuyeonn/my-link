# MyLink (마이링크) - Product Requirements Document (PRD)

## 1. 프로젝트 개요
- **프로젝트명:** MyLink (마이링크)
- **목적:** 여러 개의 웹 링크를 하나의 통합된 페이지로 모아서 공유할 수 있게 해주는 멀티 링크 프로필 서비스. 소셜 미디어 프로필, 명함 등에 활용할 수 있는 단일 URL을 제공.
- **대상 사용자:** 
  - 깃허브, 기술 블로그, 포트폴리오, 링크드인 등 흩어진 이력을 하나로 묶어 공유하고 싶은 개발자
  - 유튜브, 인스타그램 등 여러 소셜 채널을 운영하며 팬들과 소통하는 크리에이터 및 인플루언서

## 2. 핵심 기능 목록

### 🔴 필수 기능 (MVP - Minimum Viable Product)
1. **사용자 인증 및 계정 관리**
   - Firebase 기반 구글 소셜 로그인 (단일 인증)
   - 사용자 이름(Username) 기반의 고유 URL 자동 할당 (예: `domain.com/u/username`)
2. **프로필 관리**
   - 구글 계정 프로필 이미지를 기본 이미지로 자동 사용
   - 프로필 제목(닉네임) 및 간단한 소개(Bio) 작성
3. **링크 관리**
   - 새로운 링크 추가 (URL, 링크 표시 제목)
   - 기존 링크 수정 및 삭제
   - 위/아래 이동 버튼을 통한 직관적인 링크 순서 변경
4. **프로필 페이지 (퍼블릭 뷰)**
   - 설정한 프로필 이미지, 소개, 링크 목록이 표시되는 사용자 전용 페이지
   - 모바일 최적화 반응형 디자인

### 🟡 추후 기능 (기존 MVP 제외 대상 및 고도화)
1. **커스텀 프로필 이미지**
   - 별도의 프로필 이미지 직접 업로드 및 변경 기능
2. **고급 링크 관리**
   - 드래그 앤 드롭(Drag & Drop)을 통한 직관적인 링크 순서 변경
   - 링크 활성화/비활성화 토글 기능 (삭제하지 않고 숨기기)
   - 링크에 썸네일 이미지/아이콘 추가
   - 개발자/크리에이터 특화 소셜 아이콘 전용 위젯
3. **디자인 및 고급 테마 커스터마이징**
   - 맞춤형 테마 제공 (배경색, 폰트, 버튼 스타일, 다크 모드 등)
4. **데이터 통계 (Analytics) 및 부가 기능**
   - 방문자 누적 조회수 및 개별 링크 클릭수(CTR) 통계 대시보드
   - 내 프로필 QR 코드 자동 생성

## 3. 각 기능의 상세 설명

### 3.1 사용자 인증 및 계정 관리
- **인증 방식:** Firebase Authentication을 연동하여 오직 '구글 로그인'만 지원해 가입 절차를 극도로 간소화합니다. 모든 서비스는 무료로 제공됩니다.
- **Username 설정:** 구글 로그인 후 최초 1회에 한해 고유 `Username`을 설정받습니다.
  - **입력 규칙:** 3자 이상 20자 이하의 영문 소문자, 숫자, 하이픈(-)만 허용 (공백, 한글, 특수문자 불가)
  - **예약어 제한:** `admin`, `login`, `dashboard`, `api` 등의 예약어는 사용 불가
  - 실시간 중복 검사가 필수적으로 이루어져야 합니다.

### 3.2 프로필 관리
- **프로필 이미지:** 구글 소셜 로그인 시 제공받는 사용자의 구글 프로필 사진을 가져와 원형 이미지로 노출합니다. (별도의 이미지 업로드 기능은 1차 버전에서 제외)
- **소개글:** 짧고 명료한 소개를 위해 글자 수 제한(예: 150자 이내)을 둡니다.

### 3.3 링크 관리 (어드민 대시보드)
- 사용자는 로그인 후 진입하는 대시보드에서 링크 목록을 관리합니다.
- **링크 개수 및 입력 제한:**
  - 1인당 추가할 수 있는 최대 링크 개수는 과도한 데이터 누적을 방지하기 위해 **30개**로 제한합니다.
  - URL 입력 시 `http://` 또는 `https://`가 누락된 채로 저장할 경우, 자동으로 `https://`를 앞에 붙여 저장하는 편의 기능을 제공합니다.
- 추가된 각 링크 카드에는 '위로 이동', '아래로 이동' 화살표 버튼이 제공되어, 클릭을 통해 순서를 직관적으로 변경할 수 있습니다.
- **안전 삭제:** 링크 삭제 시 "정말 삭제하시겠습니까?"를 묻는 확인 팝업(모달)을 띄워 실수로 인한 데이터 유실을 방지합니다.
- **빈 화면(Empty State):** 등록된 링크가 없을 경우 대시보드에 *"첫 번째 링크를 추가해보세요."* 텍스트를 클릭 가능한 액션 버튼으로 표시하여 직관적인 추가를 유도합니다.

### 3.4 프로필 페이지 (퍼블릭 뷰)
- **URL 구조:** 초기 버전에서는 `/u/[username]` 형식으로 제공되며, 추후 서비스 안정화 시 루트 경로(`/[username]`) 지원을 고려합니다. 이 페이지는 로그인 없이 누구나 접근 가능합니다.
- **레이아웃:** 상단에는 프로필 이미지와 소개글이, 하단에는 추가한 링크들이 세로형 버튼 목록으로 렌더링됩니다.
- **링크 이동 방식:** 방문자가 링크 클릭 시, 기존 마이링크 페이지 이탈을 방지하기 위해 모든 외부 링크는 '새 탭(새 창)'에서 열리도록 강제합니다.
- **반응형:** 모바일로 주로 접속하는 환경을 고려하여, 모바일 환경에 최적화된 UI를 우선적으로 제공합니다.
- **빈 화면(Empty State):** 사용자가 추가한 링크가 없을 경우 *"아직 등록된 링크가 없습니다."*라는 메시지를 표시합니다.

### 3.5 접근 권한 및 라우팅 (Access Control)
- **퍼블릭 라우트:** `/u/[username]` (누구나 접근 가능)
- **프라이빗 라우트:** `/dashboard`, `/profile-edit`, `/link-edit` (로그인한 사용자만 접근 가능. 비로그인 시 로그인 페이지로 리다이렉트)

### 3.6 데이터 구조 (DB Schema - Firebase Firestore)
**Collection: `users`** (Document ID: `{uid}`)
- `uid`: 사용자 고유 ID
- `email`: 구글 계정 이메일
- `displayName`: 사용자 이름
- `photoURL`: 프로필 이미지 URL
- `username`: 서비스 내 고유 사용자명
- `title`: 프로필 제목
- `bio`: 프로필 소개글
- `createdAt`: 계정 생성일시
- `updatedAt`: 정보 최근 수정일시

**Sub-collection: `links`** (경로: `users/{uid}/links/{linkId}`)
- `title`: 링크 표시 제목
- `url`: 이동할 URL
- `isActive`: 링크 노출 여부 (MVP UI에서는 숨기기 기능이 제외되었으나 데이터 스키마는 유지)
- `order`: 정렬 순서
- `createdAt`: 링크 생성일시
- `updatedAt`: 링크 최근 수정일시
