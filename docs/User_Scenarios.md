# MyLink (마이링크) - 사용자 시나리오 (User Scenarios)

## 1. 방문자: 마이링크 페이지 방문 과정

### 1.1 페이지 접속
- 방문자는 **크리에이터의 모든 공유 링크를 한곳에서 확인**하기 위해 **SNS 프로필 등에 기재된 마이링크 주소(`/u/[username]`)를 클릭**한다.
- 방문자는 **현재 보고 있는 페이지의 주인이 누구인지 인지**하기 위해 **페이지 상단에 표시된 프로필 이미지, 닉네임, 소개글(Bio)을 확인**한다.

### 1.2 링크 클릭 및 이동
- 방문자는 **원하는 외부 콘텐츠로 기존 마이링크 페이지 이탈 없이 이동**하기 위해 **특정 링크 버튼을 클릭하여 새 탭(새 창)으로 연다**.

### 1.3 예외 상황 (빈 페이지)
- 방문자는 **현재 이 프로필 페이지에 등록된 링크가 없음을 인지**하기 위해 **"아직 등록된 링크가 없습니다."라는 안내 메시지를 확인**한다.

---

## 2. 소유자: 링크 추가/수정/삭제 과정

### 2.1 대시보드 진입 및 조회
- 소유자는 **자신의 프로필 페이지와 링크 목록을 관리**하기 위해 **구글 계정으로 로그인하여 대시보드(`/dashboard`) 페이지에 접속**한다.
- 소유자는 **빈 상태에서 곧바로 첫 링크를 추가**하기 위해 **대시보드에 노출된 "첫 번째 링크를 추가해보세요."라는 텍스트 액션 버튼을 클릭**한다. (최초 접속 시)

### 2.2 링크 추가
- 소유자는 **새로운 웹 주소를 자신의 프로필에 추가**하기 위해 **최대 허용 개수(30개)를 넘지 않는 선에서 대시보드 상단의 '링크 추가' 버튼을 클릭**한다.
- 소유자는 **URL 입력 시 프로토콜 누락 오류를 방지하고 빠르게 주소를 등록**하기 위해 **'제목'과 `http(s)://`가 생략된 'URL 주소(예: google.com)'를 입력하고 '저장' 버튼을 클릭**한다. (저장 시 자동으로 `https://`가 붙음)

### 2.3 링크 수정
- 소유자는 **기존에 등록해둔 링크의 제목이나 목적지 주소를 변경**하기 위해 **해당 링크 카드 내에 있는 '수정' 버튼을 클릭**한다.
- 소유자는 **원하는 최신 정보로 내용을 업데이트**하기 위해 **제목과 URL 입력란의 내용을 수정한 뒤 '저장' 버튼을 클릭**한다.

### 2.4 링크 순서 변경
- 소유자는 **가장 중요하거나 최근에 올린 링크를 상단에 배치**하기 위해 **해당 링크 카드에 위치한 '위로 이동' 또는 '아래로 이동' 화살표 버튼을 클릭**한다.

### 2.5 링크 삭제
- 소유자는 **노출을 원치 않는 링크를 삭제 절차로 진입**시키기 위해 **해당 링크 카드 내에 있는 '삭제' 버튼을 클릭**한다.
- 소유자는 **실수로 인한 데이터 유실을 방지**하기 위해 **화면에 나타난 "정말 삭제하시겠습니까?" 모달창에서 '승인' 버튼을 클릭**한다.
